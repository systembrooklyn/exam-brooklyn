# SDD Spec Kit (active)

Always plan before coding. Prefer:

- Quick features: `/brief` → `/implement`
- Complex work: `/research` → `/specify` → `/plan` → `/tasks` → `/implement`
- Review: `/audit`

Specs live under `specs/active/`. Templates and config live under `.sdd/`.
